oms.ts

/workspace/src/lib/desk/oms.ts

The only file that signs an order. submit is the door.

O1

Journal health

In the file nowAn unreadable journal row turns sending off until it is reconciled. The row must have a client id, a stage, and a ticker. An intent row must carry a positive worst-case number.

Option, not appliedKeep.

O2

Model flag

In the file nowIf the release gate is off, submit returns before risk. The reason says the model is not independently calibrated.

Option, not appliedPoint this at a score file instead of the constant.

O3

Limit orders only

In the file nowPrice must be strictly between 0 and 1. Count must be a whole number of at least 1. There is no market order type.

Option, not appliedKeep.

O4

Risk first

In the file nowsubmit calls risk.check. A no there is returned and nothing is posted.

Option, not appliedKeep that order.

O5

Cash move

In the file nowIf the destination shard cannot pay and the other shard can, it posts a transfer first. Source and destination are event_contract. A failed or non-200 move stops the order. If neither shard can pay, it stops.

Option, not appliedStop moving cash automatically.

O6

Write before send

In the file nowThe intent row is appended before the order is posted. Client id is mm1-, the ticker, y or n, and a rising count.

Option, not appliedKeep the shape so old rows stay readable.

O7

Order body

In the file nowMaker: good till canceled, post only. Taker: immediate or cancel. Both set cancel_order_on_pause.

Option, not appliedA maker that expires in 30 seconds. Or takers only.

O8

After the reply

In the file now200 or 201 is a sent row. A resting maker is looked up once, in case it filled immediately. A timeout, a 500, a 0, or a 429 is marked unknown, looked up, and never posted again. Any other status is rejected and not retried.

Option, not appliedKeep the never-repost rule.

O9

What counts as still open

In the file nowPending risk includes intents whose last stage is still intent or unknown. Once the exchange has acknowledged or cancelled it, the exchange numbers are used instead.

Option, not appliedKeep.
