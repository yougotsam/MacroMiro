gate.ts

/workspace/src/lib/desk/gate.ts

Prices YES and NO against the book. Does not send.

G1

Two sides

In the file nowYES and NO are scored separately against executable prices.

Option, not appliedKeep both sides, or score only the side already in the lead.

G2

Edge formula

In the file nowEdge = side chance − 0.02 − price − fee per contract. There is a second edge that uses the chance before any chart shift.

Option, not appliedDrop the 0.02. Or add a spread penalty.

G3

Maker

In the file nowPosts one tick above that side's bid, strictly under the ask, on the market's own price grid when the grid is supplied. Fee treated as zero on a quadratic series. Edge must be at least 1¢, or higher if a volatility shock raises the floor.

Option, not appliedJoin the bid. Or post no makers.

G4

Taker

In the file nowPays that side's ask. Count is the lesser of the budget and the size sitting on that level. Edge must be at least 4¢.

Option, not appliedA limit one tick under the ask. Or no takers.

G5

The chart cannot create the trade

In the file nowBoth edges must clear. The chart-adjusted one, and the raw model one.

Option, not appliedRaw model only. Or let the chart be enough on its own.

G6

Bad inputs

In the file nowA chance outside 0 to 1, a broken quote, a non-positive size, or a fee that is not quadratic: no ticket. An empty book is no_quote.

Option, not appliedKeep. A missing fee stays a no.

G7

Size

In the file nowThe most whole contracts whose price plus fee fit in the budget. Budget defaults to $3. Under 1 contract is recorded as no room.

Option, not appliedAlways 1 contract. Or a percent of cash.

G8

Which ticket wins

In the file nowIf several qualify, the largest edge times count wins. A taker wins a tie.

Option, not appliedPrefer the maker on a tie. Or ignore size and take the higher edge.

G9

Price band inside this file

In the file nowA price under PRICE_MIN or over PRICE_MAX is not a candidate. PRICE_MIN is 0.18. PRICE_MAX is 0.72. The last minute still refuses under 5¢ by raising the minimum, and 5¢ is already under 18¢.

Option, not appliedDelete the 5¢ comment so the file does not describe two floors.

G10

Resting orders

In the file nowrestingEdge is chance − 0.02 − the order's own price. Used when deciding to cancel or reprice a maker that is already working.

Option, not appliedAdd a fee to that line, or leave it.
