evaluator.ts

/workspace/src/lib/desk/evaluator.ts

The scan. It builds the ticket, then refuses it before risk ever sees it. These are the fail strings in the file.

E1

Market must be real

In the file nowExchange paused. No open market. Strike type must be greater-or-equal. Shard must be 0 or 2 and the price grid must exist. The market's written rule must match the series rule.

Option, not appliedKeep these. They are venue facts.

E2

Clocks and feeds

In the file nowUnder 3 seconds left. Index stale. No book. Book stale or from the future by more than half a second. Last 1-minute bar stale. Fewer than 60 volatility samples. Crypto official 60-second accumulator missing or mismatched. Fee unknown or not quadratic.

Option, not appliedSame clock choices as C12.

E3

Fast move and room

In the file nowIf that series is cooling, the reason is G2_fast_move_cooldown plus the direction. If the dollar room is 0 or less, G2_no_room.

Option, not appliedSame choices as C14 and C3.

E4

Timing policy

In the file nowIf the approval timing policy is enforced and this seconds-left bucket is not allowed, the ticket fails. Maker and taker can be turned off per bucket. The minimum price can be raised per bucket.

Option, not appliedName the buckets in this sheet once you want them changed. They are not in config.ts.

E5

Gate result

In the file nowIf gate.ts returns no candidate, the fail is G2_ plus the gate's reason. In the final seconds, makers can be switched off and the reason says so.

Option, not appliedSame choices as the gate sheet.

E6

Window block

In the file nowwindowRefusal can null the ticket and keep it as a shadow.

Option, not appliedRead this together with R11. Two window rules exist. Approve one.

E7

How a side is allowed in

In the file nowThe structure side must match the priced side. If structure has no side, a sniper setup on that same side can supply it. If structure and sniper are both empty, a fib or EMA call on that same side can supply it. If the reason starts with 20-EMA, it is refused as ema_chase. An upper wick is refused.

Option, not appliedLet structure be the only way in. Or let the fib and EMA call stay as a way in. Or remove the sniper way in.

E8

Intel after structure

In the file nowintelVerdict runs after the structure check. If it returns not ok, the ticket is a shadow and the reason is G2_ plus its why.

Option, not appliedThis file can refuse. intel-gate.ts, which it calls, currently returns ok. See that sheet.

E9

Approval

In the file nowAn approval failure is G3_ plus the reason. If the model is not approved, the reason is G3_uncalibrated_model_shadow_only and the ticket is not sent.

Option, not appliedThe config flag is true, so this shadow path is off unless that flag changes.
