intelligence.ts

/workspace/src/lib/desk/intelligence.ts

Reads the files. The chance change is applied in intel-gate.ts before the order is priced.

I1

What it reads

In the file nowmirofish-latest.json, spark-latest.json, alexandria-latest.json, desk-news.json, and the modified time of mirofish-seed.md. A missing or broken file becomes a null, not a crash.

Option, not appliedStop reading one of them, or add a file.

I2

MiroFish

In the file nowStage defaults to unavailable. Age is now minus the file's at, when that number is finite. Probability is kept only if it is between 0 and 1. usableForSettlement is always false.

Option, not appliedLet that probability move the chance by a cap. Or drop the field.

I3

Spark

In the file nowStatus and time are copied. Fresh is true only when the timestamp is a real time, not in the future, and younger than 6 hours.

Option, not appliedA stale Spark becomes a hard no. Right now it is only a label.

I4

Alexandria and Firecrawl

In the file nowAlexandria is the number of tools in the file. Firecrawl is ready when the seed file exists and is younger than 24 hours.

Option, not appliedRequire the catalog to be non-empty before a ticket, or leave it as a count.

I5

Macro list

In the file nowscheduledVeto runs on this week's and next week's calendar events. macroVeto is true when that list is not empty. The event names are returned. This function does not itself cancel an order.

Option, not appliedMake an empty or stale calendar a refuse. Or leave the veto to the calendar function.
