C2

How each market settles

In the file nowCrypto uses a 60-second index average. Gold, silver, oil, GBP, EUR, and JPY use the last 1-minute print. Decimal places are set per series.

Option, not appliedLeave this. It is the venue's rule.

C3

Option, not appliedTurn percent mode on, or write smaller dollar numbers.

C14

Fast move

In the file nowA move over 3 standard deviations across 2, 3, 4, or 5 seconds cools that series for 10 seconds, and until the 5-second move is back under 1.5 standard deviations.

Option, not appliedA longer cool-off, or none.

C15

Where cash sits

In the file nowORDER_SHARD is 2. Every market spends that one pile. Currencies are filed on shard 0 by the order path, which can move cash over.

Option, not appliedStop the automatic move, or leave it.
